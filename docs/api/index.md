## API Reference

This section documents the public Python API surface exposed by XLA bindings.

- xla.python.xla_client: Core client types, enums, and helpers
- xla.python_api.xla_shape: Shape construction and conversion utilities
- xla.python_api.xla_literal: Literal conversion helpers
- xla.python_api.types_: Type conversion records and mappings
